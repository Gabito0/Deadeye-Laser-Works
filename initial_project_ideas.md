# Project Ideas

## 1. E-commerce Website for Laser Engraving

- Create a website for laser engraving.
- Users can create an account.
- Users can add orders to the cart.
- Users can submit orders.

**Stack:**

- PostgreSQL
- Express
- Node
- React (possibly with Vite)

## 2. Recipe App

- Create a website that allows users to find food recipes.
- Users can browse the app without an account.
- Users need to create an account to save recipes.

**Stack:**

- PostgreSQL
- Express
- Node
- React (possibly with Vite)

## 3. Book Discovery App

- Create a website to help users find books and check a short summary of each book.
- Users can add books to their read list.

**Stack:**

- PostgreSQL
- Express
- Node
- React (possibly with Vite)
